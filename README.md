Entry for `u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162` (make.fun,
$2, free to enter). The program writes one joke about office life — 200
characters at most — to `/output/entry.txt`.

## The joke

> The office plants are the only ones thriving here — watered once a week, no
> standup, and nobody has ever asked them for a status update.

136 characters, one line. Written for the judge's brief: a single sentence
that lands as a joke about office life, with the punchline paying off the
setup (the plants thrive precisely because they escape the rituals that drain
everyone else); a specific detail (standup, status updates) rather than a
generic complaint; clear on first read.

## Run

```sh
python3 main.py            # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
